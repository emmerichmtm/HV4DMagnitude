# Main theorem to verify

For fixed dimension \(d\), consider a recursive state represented as a signed sum of \(S\) **weighted monotone-pair terms**

\[
\Phi(\xi)
=
\prod_i q_i(\xi_i)
\prod_e
\mathbf 1[
\xi_{j_e}\triangleleft_e f_e(\xi_{i_e})
],
\]

where:

- each \(q_i\) is a one-dimensional step density;
- each \(f_e\) is a monotone step function;
- \(\triangleleft_e\) is a decorated strict/non-strict relation;
- EMPTY/FULL and open/closed endpoint semantics are explicit;
- the total one-dimensional breakpoint complexity is \(N\).

Let \(B\) be the product of all newly easy one-/two-sided grounded masks, and let \(\mathcal G'\) be a **future-complete grid** generated by the remaining \(m\) hard orthants and all coordinates that can become descendant masks before the next compression.

The proposed simplification theorem says:

\[
\widetilde F
=
\mathbf E_\mu[F B\mid \mathcal G']
\]

can be represented in the same class with

\[
\boxed{S' \le C_d S}
\]

for a constant \(C_d\) depending only on fixed dimension \(d\), not on \(n,m,N\).

The proposed complexity is

\[
\boxed{
T_{\mathrm{compress}}
=
O_d\!\left(S(N+m)\log(N+m)\right)
}
\]

or

\[
\boxed{
O_d(S(N+m))
}
\]

if all relevant event lists are already sorted.

The stored compressed representation should use

\[
\boxed{O_d(S'm)}
\]

one-dimensional interval/prefix records.

With Chan's cutting recursion unchanged, the asymptotic running time should remain

\[
\boxed{\widetilde O_d(n^{d/3})}.
\]

In particular:

\[
T_4(n)=\widetilde O(n^{4/3}),
\qquad
T_6(n)=\widetilde O(n^2),
\qquad
T_8(n)=\widetilde O(n^{8/3}).
\]

This is a **simplification of Chan's symbolic integration**, not an improvement of the exponent.

# Conceptual motivation: magnitude and product measures

The 4-D derivation was discovered using \(\ell_1\)-magnitude.

For an anchored/downward-closed set \(D\),

\[
\operatorname{Mag}(D)
=
\sum_{S\subseteq[d]}
2^{-|S|}HV_S(D).
\]

Equivalently, ordinary \(\ell_1\)-magnitude is represented by the positive product measure

\[
\mu_M
=
\bigotimes_{i=1}^d
\left(\delta_0+\frac12\lambda_i\right).
\]

The same symbolic derivation should also work with

\[
\mu_i=\lambda_i,
\]

which gives Lebesgue hypervolume directly.

The implementation should therefore support at least two exact-oracle modes:

1. Lebesgue product measure;
2. magnitude product measure.

Magnitude is especially useful for exposing boundary mistakes because of the atom at zero.

# Mandatory endpoint conventions

These are not cosmetic.

The audit found real failures when these were handled incorrectly.

## Strict staircase residuals

For grounded quadrants, the uncovered residual should be represented with strict inequalities of the form

\[
x_j < f_{ij}(x_i),
\]

not blindly with \(\le\).

Under Lebesgue measure the difference is null; under magnitude it can have positive mass.

## Decorated generalized inverses

Never encode an empty prefix simply as the number \(0\).

Use an explicit bound object, e.g.

```python
Bound(
    kind="empty" | "finite" | "full",
    value=...,
    closed_left=...,
    closed_right=...
)
```

or an equivalent exact representation.

The states

- empty prefix,
- singleton `{0}`,
- `[0,\theta)`,
- `[0,\theta]`

must remain distinct.

## Future-complete grid

The tower-property argument is valid only if every later mask is measurable with respect to the parent compression grid.

Therefore the grid must include every coordinate that may become a descendant mask before the next compression, including relevant cut coordinates and inherited cell-boundary coordinates.

Do not coarsen more aggressively.

# Core general-dimensional pair-elimination claim

The generalized report proposes the following structural lemma.

## Pair-Elimination Lemma

Take one weighted monotone-pair term in \(p\) variables and choose two variables \(x,y\) to eliminate.

All constraints incident to \(x\) or \(y\) can be normalized into decorated lower/upper bounds

\[
L_x(z)\prec x\preceq U_x(z),
\qquad
L_y(z)\prec y\preceq U_y(z),
\]

where every candidate bound is a unary monotone function of one surviving variable.

Since \(p\) is fixed, there are only \(O(p)\) candidate bounds.

Partition parameter space according to which candidates attain the active lower and upper bounds.

The number of active-bound labels must be bounded by a function of \(p\) only.

On each label:

1. the mutual \(x,y\) constraints reduce to at most one lower and one upper monotone staircase;
2. finite differences reduce interval integration to a constant number of prefix integrations;
3. each branch evaluates to either:
   - a product of unary cumulative records, or
   - a sum of unary cumulative records;
4. every branch condition between survivors is again a pairwise monotone predicate.

Therefore eliminating \(x,y\) yields a signed sum of at most

\[
B_p=O_p(1)
\]

weighted monotone-pair terms in \(p-2\) variables, with total breakpoint complexity \(O_p(N)\).

This is the lemma you must verify carefully.

# What must be proved, not merely observed

Do not accept "finite dimension" as sufficient by itself.

You must explicitly establish:

1. **Finite active-bound candidate count.**
   For every eliminated variable, list all possible lower/upper candidates and bound their number by a function of \(p\) only.

2. **Finite label count.**
   Bound the number of possible combinations of active candidates.

3. **Separable branch formulas.**
   For each label, show symbolically that the integrated mass is a product or sum of unary cumulative records.

4. **Closure of branch conditions.**
   Show every residual condition among surviving variables is still a comparison of unary monotone functions.

5. **Complement handling.**
   Show that expanding complements creates at most a dimension-dependent constant factor.

6. **Breakpoint complexity.**
   Same-variable comparisons may cross many times. Those crossings must increase unary breakpoint complexity, not primitive count.

7. **No hidden instance-size dependence in \(B_p\).**
   The branching constant may depend on \(p\), but not on \(N,m,n\).

If any of these fails, isolate the exact failure and give the smallest counterexample you can find.

# 4-D base case

Treat the already-audited \(4D\) case as a base case and regression oracle.

The six easy staircase constraints are:

\[
f_{12}, f_{13}, f_{14}, f_{23}, f_{24}, f_{34}.
\]

The \(2+2\) factorization uses

\[
r(x_1)=(f_{13}(x_1),f_{14}(x_1)),
\qquad
s(x_2)=(f_{23}(x_2),f_{24}(x_2)).
\]

The source staircase \(f_{12}\) has the exact two-branch prefix formula

\[
C_f(A,B)
=
\begin{cases}
X(A)Y(B), & B<f(A),\\
P(A)+Q(B), & B\ge f(A),
\end{cases}
\]

with decorated endpoint semantics.

The meet contraction is

\[
\sum_{\alpha,\beta}
c_\alpha d_\beta
G(r_\alpha\wedge s_\beta)
=
\int A(u)B(u)\,d\nu(u).
\]

Regression tests must reproduce the audited 4-D exactness before touching 6-D or 8-D.

# Compression as elimination in 2d variables

The clean general compression proof is:

- current coordinates: \(x=(x_1,\dots,x_d)\);
- new grid-location variables: \(y=(y_1,\dots,y_d)\).

For one current term \(F(x)\), define

\[
N_F(y)
=
\int
F(x)
\prod_{i=1}^d
\mathbf 1[
\pi_i^-(y_i)\prec x_i\preceq \pi_i^+(y_i)
]
\,d\mu(x).
\]

Before elimination, this is itself one weighted monotone-pair term in \(2d\) variables.

Repeatedly pair-eliminate the old \(x\)-variables.

The output should be a constant signed list of weighted monotone-pair terms in the new \(y\)-variables.

Divide by the product of one-dimensional cell masses to obtain the conditional expectation.

This should give the representation closure

\[
S'\le C_d S.
\]

Verify this construction directly.
